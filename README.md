# 昼夜 · 世界时钟

独立静态网页。

- 黑底红色点阵地图，亮色为白昼、暗色为黑夜，曲线为真实昼夜分界。地图每 30 秒更新；后台暂停绘制。
- 大点为所选位置，左下为当地 24 小时时间，左上为下一次日出／日落。极昼、极夜期间若未来 48 小时没有日出日落，左上隐藏。
- 默认通过 GeoJS 获取 IP 大致位置。点击城市或设置可以选择城市、自定义坐标及 IANA 时区；手动位置保存在当前浏览器。
- 定位按钮调用浏览器设备定位，需要浏览器许可及 HTTPS / localhost 等安全环境。位置名称通过 BigDataCloud 查询，时区采用设备时区；可在设置中手动更正。
- 尝试通过 WorldTimeAPI 公共 UTC 校时，失败时使用本机时间；离线仍可选城、看地图和昼夜变化。IP 位置可能是运营商或代理出口位置，不等于精确设备位置。
- 右下可切换全屏；手机竖屏也有独立布局。没有构建步骤、框架或远程地图依赖。

地图点阵根据 Natural Earth 1:110m 陆地轮廓采样，省略南极洲，与参考构图一致；海岸线为概略效果。数据属于公有领域：https://www.naturalearthdata.com/about/terms-of-use/ 。太阳位置采用 NOAA 太阳几何公式，日出日落按太阳中心高度 −0.833° 估算，不计当地山地与特殊大气条件。

`index.html`：页面；`styles.css`：外观；`clock.js`：时钟、太阳计算、定位和交互；`map-data.js`：本地点阵数据。
